# Learning Log

## 2025-10-10: TypeScript Basics

*   "Skim" [The Basics](https://www.typescriptlang.org/docs/handbook/2/basic-types.html) page. Just get a feel for the syntax.
*   "Read carefully" the [Everyday Types](https://www.typescriptlang.org/docs/handbook/2/everyday-types.html) chapter. This is where you should spend the majority of your time. Focus on truly understanding type vs. interface, and how to type functions and objects.

## 2025-10-10: React Basics

*   Read [Your First Component](https://react.dev/learn/your-first-component) to understand that a React component is a JavaScript function that returns JSX.
*   Read [Passing Props to a Component](https://react.dev/learn/passing-props-to-a-component) to learn how a parent component passes data to a child.
*   Read [Responding to Events](https://react.dev/learn/responding-to-events) to understand the `onClick` handler for making components interactive.
